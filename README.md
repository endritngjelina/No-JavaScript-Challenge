# No-JavaScript Challenge

A collection of frontend challenges designed to explore what can be accomplished using **HTML and CSS alone**, without relying on JavaScript.

The project demonstrates different approaches to creating interactive elements, animations, layouts, and user interface experiences using native HTML and CSS features.

## 🎯 Purpose

The goal of this project is to challenge the assumption that JavaScript is always required for interactive web experiences.

Each challenge explores different HTML and CSS techniques that can be used to create functionality and visual effects while keeping the implementation completely JavaScript-free.

## ✨ Features

- 🚫 No JavaScript
- 🎨 Modern HTML/CSS designs
- 🧩 Multiple independent challenges
- ✨ CSS animations and transitions
- 🖱️ CSS-based interactions
- 📱 Responsive web layouts
- 💡 Creative use of native HTML elements and CSS selectors
- 📚 Useful examples for learning frontend development
